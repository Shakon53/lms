# Instructor guide

## Create and publish a course

1. Open **Courses** and create a draft course.
2. Add an overview, instructors, chapters, and lessons.
3. Add quizzes, assignments, videos, files, or programming exercises where needed.
4. Use Student View to verify navigation and access before publishing.
5. Configure enrollment, pricing, evaluation, and certificate requirements in
   the publish settings.

## Run a batch

1. Create the batch, set dates and timezone, and add instructors.
2. Attach courses and enroll learners.
3. Add timetable entries, live classes, announcements, and assessments.
4. Review attendance, submissions, progress, and evaluation schedules regularly.

## Assessment practice

- State the expected evidence and passing conditions before learners submit.
- Give actionable feedback and avoid changing marks without leaving an explanation.
- Confirm learner identity and completion requirements before issuing certificates.
